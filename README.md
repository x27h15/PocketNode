## 💡 О проекте

Старые смартфоны часто пылятся в ящиках, хотя их аппаратная начинка превосходит многие платы вроде Raspberry Pi Zero:
* **Встроенный ИБП:** аккумулятор телефона защищает сервер от скачков напряжения и отключений электричества.
* **Минимальное энергопотребление:** всего 1–2 Ватта при питании от обычной USB-зарядки.
* **Встроенный Wi-Fi, Bluetooth и память:** не требуются дополнительные модули и флешки.
* **Нативный Linux (chroot):** дистрибутив Debian работает напрямую через ядро Linux без медленной эмуляции `proot` и без багов `ptrace`.

**PocketNode** автоматизирует весь процесс настройки: от прошивки и рутирования до развёртывания OpenSSH, DNS-фильтров, прокси и панели управления `setL`.

## 🚀 Быстрый старт (Пошаговое руководство)

### Подготовка:
1. Скачайте свежий релиз со страницы [Releases](https://github.com/mineb/pocketnode/releases):
   * `pocketnode-installer.exe` (для Windows) или бинарник для Linux/macOS.
   * `recovery.tar` (находится в папке `assets/`).
   * Прошивку LineageOS 18.1 для Galaxy A5: `lineage-18.1-xxxx-UNOFFICIAL-a5lte.zip`.

---

### ШАГ 1: Прошивка TWRP Recovery
1. Полностью выключите телефон.
2. Зажмите комбинацию кнопок: **`Громкость ВНИЗ` + `Кнопка ДОМОЙ (Home)` + `Включение`**.
3. При появлении предупреждающего экрана нажмите **`Громкость ВВЕРХ`** для входа в **Download Mode**.
4. Подключите телефон к компьютеру через USB.
5. Откройте **Odin**:
   * Нажмите кнопку **AP** и выберите `assets/recovery.tar`.
   * Во вкладке **Options** обязательно **СНИМИТЕ галочку Auto Reboot**.
   * Нажмите **Start** и дождитесь надписи `PASS!`.
6. После прошивки зажмите: **`Громкость ВВЕРХ` + `Home` + `Включение`** для первого входа в TWRP.

---

### ШАГ 2: Установка LineageOS 18.1
1. В меню TWRP выберите: **Wipe** ➔ **Advanced Wipe**.
2. Отметьте разделы:
   * `Dalvik / ART Cache`
   * `Cache`
   * `Data`
   *(ВНИМАНИЕ: Раздел `System` вайпать **НЕ нужно**! Всё работает без затрагивания system).*
3. Сдвиньте слайдер **Swipe to Wipe**.
4. Вернитесь в главное меню TWRP ➔ **Install** ➔ выберите архив `lineage-18.1-xxxx-a5lte.zip` и сдвиньте слайдер.
5. Нажмите **Reboot System**.

> [!WARNING]
> **Не прошивайте архив Magisk!** На Android 11 / MSM8916 новые версии Magisk повреждают заголовок `boot.img` и вызывают циклическую перезагрузку. PocketNode использует нативную системную авторизацию ADB Root.

---

### ШАГ 3: Включение режима разработчика
После первой загрузки телефона:
1. Откройте **Настройки** ➔ **О телефоне**.
2. В самом низу нажмите **7 раз подряд** на пункт **«Номер сборки»**.
3. Вернитесь в **Система** ➔ **Для разработчиков**:
   * Включите тумблер **«Отладка по USB»**.
   * В пункте **«Рут-доступ»** выберите **«Только ADB»**.
4. Подключите телефон к ПК по USB и разрешите отладку на экране телефона.

---

### ШАГ 4: Запуск установщика PocketNode
Запустите `pocketnode-installer.exe` на компьютере. 

Установщик в автоматическом режиме:
- [x] Обнаружит подключённое устройство по ADB;
- [x] Настроит постоянный доступ к ADB по сети (`порт 5555`);
- [x] Смонтирует системные каталоги (`/dev`, `/proc`, `/sys`) и память телефона (`/sdcard`) в Debian;
- [x] Сгенерирует персональный SSH-ключ (`~/.ssh/id_pocketnode`) и пропишет его на сервере;
- [x] Зарегистрирует фоновую службу OpenSSH как постоянный системный сервис Android (`init`);
- [x] Установит утилиту управления `setL` в `/usr/local/bin/`;
- [x] Настроит безопасный DNS (Quad9 9.9.9.9) и прямые команды перезагрузки ядра.

**После завершения кабель USB можно отключить навсегда!**

## 🔑 Подключение к серверу по SSH

Сервер автоматически поднимается при каждом включении телефона на стандартном порту `22`:

```bash
# Подключение с основного ПК:
ssh root@192.168.1.xxx

# Подключение с указанием ключа (с любого другого устройства):
ssh -i ~/.ssh/id_pocketnode root@192.168.1.xxx
```

## ⚡ Панель управления `setL`

Внутри сервера введите команду **`setL`** (или `setup`, `setup-loader`):

```text
================================================================
           ⚡ setup-loader (setL) — Панель управления           
================================================================
 IP: 192.168.1.191   | DNS: 9.9.9.9       | Прокси: ВЫКЛ
 RAM: 733M / 1884M   | Батарея: 89%       | CPU Темп: 38°C
 Uptime: 0h 30m      
================================================================
 1. 🌐 Управление Прокси (Вкл / Выкл / Настройка)
 2. 📡 Настройка DNS (Quad9, Cloudflare, Google, AdGuard, Свой)
 3. 🚀 Быстрая оптимизация системы (Очистка ОЗУ, кэша)
 4. ⚡ Режим работы процессора (CPU Governor)
 5. 📦 Установка базовых пакетов сервера (Essentials Pack)
 6. 🔑 Проверка и статус службы SSH
 7. 🔄 Перезагрузка сервера (Reboot)
 8. ⏹  Выключение сервера (Poweroff)
 0. 🚪 Выйти
================================================================
```

### Возможности `setL`:
1. **🌐 Прокси-клиент:** Интерактивная настройка (адрес, логин, пароль), тест соединения через curl, применение системных переменных `http_proxy` и настройка APT.
2. **📡 Менеджер DNS:** Переключение в 1 клик между **Quad9** (`9.9.9.9`), **Cloudflare** (`1.1.1.1`), **Google** (`8.8.8.8`), **AdGuard DNS** (`94.140.14.14` с фильтрацией баннеров) или собственный IP с замером времени ответа.
3. **🚀 Очистка и ускорение:** Сброс кэшей ОЗУ (`drop_caches`), компактизация памяти ядра, очистка каталога `/tmp` и кэша APT.
4. **⚡ CPU Governor:** Переключение ядер в режим `performance` (максимальная частота для сервера), `interactive` или `powersave`.
5. **📦 Essentials Pack:** Установка базового набора в 1 клик (`git`, `build-essential`, `htop`, `tmux`, `ncdu`, `curl`, `wget`, `python3`, `pip`, `net-tools`).
6. **🔄 Безопасное питание:** Перезагрузка (`reboot`) и отключение (`poweroff`) напрямую через ядро Linux (`/proc/sysrq-trigger`).
7. **🎭 Демо-режим (Dry-run / Simulation):** Безопасное тестирование интерфейса и меню без нагрузки на реальное устройство.

### 🎭 Тестирование в Демо-режиме (без нагрузки)

Вы можете протестировать установщик и саму панель `setL` без подключения телефона и без изменения реальных файлов:

```powershell
# Способ 1: Флаг командной строки
.\pocketnode-installer.exe --demo

# Способ 2: Переменная окружения DEMO (PowerShell)
$env:DEMO = "1"
.\pocketnode-installer.exe

# Способ 3: В Linux / Termux / SSH на телефоне
DEMO=1 setL
```
*Также переключатель демо-режима доступен непосредственно в главном меню обеих программ.*

## 🛠 Сборка из исходников

Для сборки проекта на ПК требуется установленный **Go 1.22+**:

```powershell
# 1. Клонируйте репозиторий:
git clone https://github.com/mineb/pocketnode.git
cd pocketnode

# 2. Соберите утилиту для телефона (ARMv7) в папку assets:
$env:GOOS="linux"; $env:GOARCH="arm"; $env:GOARM="7"
go build -ldflags="-s -w" -o assets/setL ./cmd/setL

# 3. Соберите установщик для Windows (или Linux/macOS):
go build -ldflags="-s -w" -o pocketnode-installer.exe ./cmd/installer
```

Или просто запустите готовый скрипт:
```powershell
.\build.ps1
```
